# HW-L04-02 - TypeScript Team Task Manager

پیاده‌سازی موارد تمرین:
- مدیریت اعضای تیم (نام + نقش مدیر/عضو)
- مدیریت پروژه‌ها
- مدیریت تسک‌های هر پروژه
- عنوان، توضیح، اولویت، وضعیت، سررسید، مسئول
- افزودن/ویرایش/حذف/تغییر وضعیت
- جستجو و فیلتر بر اساس عنوان، وضعیت، اولویت، مسئول و بازه تاریخ
- صفحات مجزا با React Router
- LocalStorage
- ثبت‌نام و ورود اجباری + Protected Routes
- نمایش کاربر فعال
- یادآوری تسک‌های نزدیک به سررسید
- TypeScript + Tailwind CSS
